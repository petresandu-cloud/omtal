Worth knowingUnderstanding

The maker links its other identities (sameAs)

What is checked Decided by code from: product.graph.

Why it matters

sameAs links to the app stores, GitHub, LinkedIn or Wikidata let an engine merge the site's entity with what it already knows from elsewhere.

Check your site

pip install git+https://github.com/petresandu-cloud/omtal
omtal audit https://your-product.example

The report names this rule as entity.same-as.
